Cómo usar el instrumento

  1. Haz clic en "Activar Sensor" para comenzar a monitorear el movimiento de tu dispositivo.
  2. Sostén tu dispositivo en posición vertical (como si estuvieras leyendo).
  3. Mueve tu dispositivo hacia abajo y luego hacia arriba para disparar un acorde.
  4. El acorde se activará en el momento exacto en que el movimiento cambie de "bajando" a "subiendo".
  5. Puedes cambiar el tipo de acorde usando los botones de selección de acorde.
  6. Utiliza "Probar Acorde" para escuchar el sonido sin necesidad de mover el dispositivo.

Nota: Este instrumento utiliza la API de DeviceOrientation que puede no estar disponible en todos los navegadores o dispositivos. Asegúrate de permitir el acceso a los sensores cuando se solicite.
